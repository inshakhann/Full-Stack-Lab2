IEEE-STYLE CONFERENCE PAPER TEMPLATE — HTML + CSS

OPEN THE ASSIGNMENT
1. Extract the ZIP file.
2. Open the IEEE-Paper-Template folder.
3. Double-click index.html to open the template in your browser.
   Alternatively, open the folder in VS Code and use Live Server.
No installation or internet connection is required.

FILES
index.html — title, authors, abstract, keywords, sections and examples.
style.css  — typography, page dimensions, author grid and two-column body.
README.txt — usage and assignment explanation.

WHAT IS INCLUDED
- Full-width centred paper title.
- Six editable author/affiliation placeholders, arranged in two rows.
- Two-column body with justified Times New Roman text.
- Abstract, keywords, numbered sections and lettered subsections.
- Equation with a right-aligned number.
- Figure placeholder with caption below; table with caption above.
- Acknowledgment and bracketed reference examples.
- Responsive screen styles and a US Letter print stylesheet.

HOW THE LAYOUT WORKS
The authors use CSS Grid with three columns.
The paper body uses column-count: 2 and column-gap: .25in. Content flows
from the left column to the right in normal reading order.
On narrow phone screens, the text stacks into one column for readability.
The print stylesheet restores two columns regardless of screen width.

EDIT YOUR PAPER
Replace the title, author details, abstract, keywords and instructional text.
Remove unused author divs and adjust the author grid if desired.
Replace the figure-placeholder div with, for example:
<img src="images/figure1.png" alt="Description of your research figure">
Create the images folder and place your real figure there.
Replace example equation, table values and references with your actual work.
Renumber section headings and references manually if you add or remove them.

PRINT OR SAVE AS PDF
Press Ctrl+P on Windows or Cmd+P on Mac.
Choose Letter paper, portrait orientation, and 100% scale.
Disable browser headers and footers to remove dates, URLs and page numbers.
Allow the stylesheet's page margins; do not select custom additional margins.
Preview all pages before saving. Added content and font availability can change
pagination; browser column fragmentation varies between rendering engines.

SOURCE AND SCOPE
Based on the supplied conference-template-letter.docx: a 24-point title,
11-point author names, 9-point abstract, 10-point body, approximately 0.625-inch
side margins, 0.75-inch top margin, 1-inch bottom margin and 0.25-inch column gap.
This is an IEEE-style HTML/CSS assignment template, not an official IEEE
submission file or a claim of submission compliance. Use the destination
conference's official template for actual submission. The example references
are deliberately incomplete placeholders, not real source citations.
The supplied Word file has not been changed.
