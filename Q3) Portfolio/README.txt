INSHA KHAN — TWO-COLUMN PORTFOLIO

HOW TO OPEN
1. Extract the complete ZIP file (right-click > Extract All on Windows).
2. Open the extracted Insha-Khan-Portfolio folder.
3. Double-click index.html to view the portfolio in your browser.
   You can also open the folder in VS Code and use Live Server if installed.
No installation, internet connection, or build command is needed to display the page.
Email, telephone, and external profile links use their respective apps or internet access.

FILES
index.html        All content and semantic HTML structure
style.css         All styling, two-column layout, and responsive rules
images/profile.jpeg   Your supplied profile photograph
README.txt        These instructions

ABOUT THE ASSIGNMENT
This project uses HTML and CSS only, with no JavaScript or frameworks.
The .portfolio CSS Grid has two columns: the left profile/skills sidebar and
right main content area. Below 700px, columns stack vertically for mobile.
HTML elements include aside, main, header, nav, section, article, and footer.
Project details use native HTML details/summary and work without JavaScript.
CSS variables control the navy, ivory, and gold palette.

EDITING
Change text and links in index.html.
Change colours in the :root section at the top of style.css.
Replace images/profile.jpeg with another photo using the same filename.
